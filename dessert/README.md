# Tokey Coconut Candy 🍬🥥

Website branding, marketing funnel dan e-commerce untuk bisnes manisan/dessert dari rumah.

## Upload gambar produk
Masukkan gambar sebenar dalam folder `dessert/images/`. Nama fail disyorkan: `produk-01.jpg`, `produk-02.jpg`, `produk-03.jpg`, `hero.jpg`, `logo.png`. Format JPG, PNG atau WebP.

Folder `images/` sudah disediakan dengan fail `.gitkeep`.

## Rangka laman (akan dibangunkan selepas gambar diterima)
- Hero visual dan cerita brand
- Katalog produk dengan foto, variasi, harga dan status stok
- Cart, pilihan pickup/delivery dan butiran pelanggan
- Checkout (integrasi payment gateway selepas maklumat perniagaan disahkan)
- CTA WhatsApp, FAQ, testimoni sebenar dan info penghantaran
- Mobile-first, SEO dan analitik
